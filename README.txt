راست‌چین چت Cursor
====================

این ابزار جهت هر پاراگراف چت Cursor را از روی اولین حرف همان پاراگراف
تنظیم می‌کند و بعد از بستن Cursor هم می‌ماند.

محل نصب Cursor مهم نیست. apply.bat خودش آن را پیدا می‌کند.
اگر پیدا نکرد، پوشه‌ای را می‌پرسد که Cursor.exe داخل آن است.

این راهنما همان README.md است، برای باز کردن در Notepad.


این ابزار چه می‌کند
------------------
- پاراگرافی که با فارسی یا عربی شروع شود راست‌چین می‌شود.
- پاراگرافی که با انگلیسی شروع شود چپ‌چین می‌شود.
- جمله ترکیبی هم از روی حرف اول همان پاراگراف تصمیم گرفته می‌شود.
  مثال: «سلام Hello» راست‌چین است. «Hello سلام» چپ‌چین است.
- کادر نوشتن چت هم همین قاعده را دارد.
- بلوک کد چپ‌چین می‌ماند.
- ویرایشگر کد، ترمینال و منوها عوض نمی‌شوند.

فقط روی ویندوز کار می‌کند.


گرفتن پوشه
----------
در صفحه گیت‌هاب دکمه Code و بعد Download ZIP را بزنید و فایل را Extract
کنید. apply.bat را از داخل خود zip اجرا نکنید.

یا با Git:

  git clone https://github.com/mehdiyousefzadeh/Cursor-Chat-RTL.git


نصب
---
1. Cursor را از منوی File با Exit ببندید.
2. Task Manager را باز کنید و مطمئن شوید Cursor.exe دیگر در لیست نیست.
   بستن پنجره کافی نیست؛ برنامه ممکن است در پس‌زمینه باز بماند.
3. روی apply.bat دو بار کلیک کنید.
4. اگر ویندوز اجازه مدیر (Administrator) خواست، Yes را بزنید.
   این پنجره فقط وقتی می‌آید که Cursor داخل پوشه محافظت‌شده،
   مثل Program Files، باشد. نصب داخل پوشه کاربر این اجازه را نمی‌خواهد.
5. صبر کنید تا مسیر نصب‌هایی که به‌روز شده‌اند نوشته شود.
6. Enter را بزنید و Cursor را دوباره باز کنید.

اگر نصب خودکار پیدا نشد، پنجره مسیر را می‌پرسد.
روی میانبر Cursor راست‌کلیک کنید، Open file location را بزنید،
و همان پوشه را بچسبانید. پوشه باید Cursor.exe را داخل خودش داشته باشد.

می‌توانید مسیر را از اول هم بدهید:

  apply.bat "D:\Apps\Cursor"

اگر چند نسخه Cursor نصب باشد، هر نسخه‌ای که پیدا شود به‌روز می‌شود.

نتیجه در install-log.txt کنار همین پوشه نوشته می‌شود.
نسخه پشتیبان فایل‌های اصلی اینجاست:

  %APPDATA%\Cursor\User\cursor-chat-bidi\backup


امتحان
------
در چت این دو پاراگراف را جدا بنویسید:

  سلام. این جمله باید از راست شروع شود.
  Hello. This paragraph should start on the left.

در پاسخ دستیار هم هر پاراگراف جداگانه، از روی اولین حرف خودش، جهت می‌گیرد.


اگر Cursor را آپدیت کردید
-------------------------
آپدیت فایل‌های داخل پوشه نصب را عوض می‌کند و این قابلیت پاک می‌شود.
Cursor را کامل ببندید و دوباره apply.bat را اجرا کنید.


برگرداندن به حالت قبل
---------------------
1. Cursor را کامل ببندید.
2. روی restore.bat دو بار کلیک کنید. اگر ویندوز اجازه مدیر خواست، Yes را بزنید.
3. Cursor را دوباره باز کنید.

restore.bat فقط وقتی کار می‌کند که قبلاً apply.bat با موفقیت
نسخه پشتیبان گرفته باشد.


اگر پنجره نصب خطا داد
---------------------
- «Cursor هنوز باز است»: در Task Manager همه Cursor.exe را ببندید.
- «اجازه مدیر»: دوباره apply.bat را اجرا کنید و Yes را بزنید.
- «نصب Cursor پیدا نشد»: مسیر را از Open file location بردارید.

اگر بعد از نصب Cursor باز نشد، آن را از Task Manager ببندید
و restore.bat را اجرا کنید.
